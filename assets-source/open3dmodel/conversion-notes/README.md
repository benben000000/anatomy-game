# Conversion notes

One file per conversion stage: inspection, trim, retexture, export.

**This directory is empty because no conversion has been run.** No asset is
licensed, and the pipeline specification in docs/three-d-asset-pipeline.md states
that no conversion may begin before the licence record is complete.

A stage note is written only after the stage has actually been run. An empty
directory is a truthful record; a speculative note describing steps that were
never executed is not.
